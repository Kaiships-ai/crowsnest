# Boards

Crowsnest boards open as tabs in the Lead Studio workspace: Today (the morning screen), Funnel (driven in [funnel.md](funnel.md)), My channel (the own Instagram channel), Rivals (the tracked rivals), Plan (planned reels by month, week and day), Gate 1 (approve a proposed plan, driven in [baseline.md](baseline.md)), Gate 2 (approve a publish, driven in [gate2.md](gate2.md)) and Agents (the MCP journal and agent tokens), all read through the engine bridge. Each connector's state and key live in Settings > Sources, driven in [connectors.md](connectors.md). Architecture: `documents/architecture/boards.md`.

## Sub-features

- Board tab (`board-tab`), opened from the sidebar rows (`ls-nav-row`, `data-nav-id`) or the tab bar "+" menu, Lead Studio group (`new-tab-board`, `data-board-id`).
- App menu: top-level Boards menu, one item per board. On macOS the app menu itself is named Lead Studio, so boards get their own menu.
- Today: `today-offer`, `today-offer-step`, `today-funnel`, `today-step` (`data-step-id`), `today-drop` (`data-status`), `today-gates`, `today-open-gate`, `today-gate-plans`, `today-gate-drafts`, `today-pulls`, `today-pull-row` (`data-connector-id`, `data-state`, with a `state-pill`), `today-workspaces`, `today-workspace-row`; each block has one `source-tag`, and each number is a `kpi-value` (`data-state`: `value`, `partial`, `not-connected`, `pull-failed`, `pull-partial`, `no-data`) with a `kpi-state` badge, and `open-sources` on a not connected one.

- Rivals: `rivals-group` (`data-group`: `take`, `learn`, `avoid`, `unsorted`), `rivals-channel-row` (`data-handle`), `rivals-outlier` (`data-video-id`, `data-handle`), `rivals-outlier-open`, `rivals-evidence-card` (`data-video-id`, `data-tag`), `rivals-evidence-open` (`data-url`), `rivals-add-input`, `rivals-add-submit`, `rivals-add-message` (`data-status`).

the pane's `data-claude` (`alive`, `exited`, `closed`, `unknown`), `cook-option` (`data-index`) with `cook-recommended`, `cook-other`, `cook-other-input`, `cook-other-send`, `cook-approval-command`, `cook-allow`, `cook-always`, `cook-deny`, `cook-reply-input`, `cook-reply-send`, `cook-banner`, `cook-banner-close`, `cook-menu` (its Show terminal item has no testid), `cook-stop`, `cook-stop-dialog`, `cook-stop-keep`, `cook-stop-confirm`, `cook-video` (`data-kind`: `none`, `draft`, `final`, `version`) with `cook-video-player`, `cook-video-empty`, `cook-video-label`, `cook-version-v<N>` (`data-on`), `cook-video-change`, `cook-compare` (from the card's `cook-compare` button; - Load states: `board-state-loading`, `board-state-empty`, `board-state-error` with `board-retry`; `board-refresh` reloads a ready board.

## How to get to it (user POV)

Click a row in the sidebar (Today, Funnel, My channel, Rivals, Plan, Studio, Agents), or "+" in the tab bar and a board under Lead Studio, or the Boards app menu. Gate 1 and Gate 2 open from Today's gate lines. The sidebar's Sources row opens Settings > Sources.

## Gotchas

- The `own-01`, `rivals-01` and `agents-01` baselines are shot on `baseline-lane.sh` (stopped clock, fixed seed) after the journeys before them in its list; the journal and the pull times depend on that. Compare with `baseline-lane.sh --compare`, and write new ones with `UPDATE_BASELINE=1` on the same command, then look at each shot before approving it.

- `plan-01` moves the seeded draft and adds a reel, so a rerun needs a fresh lane, and it runs before the cook journeys (`cook-01`, `cook-pane-*`, `cook-restart-01`): they Cook `plan-e2e-full`, whose chip then reads `cooking`, and `plan-01` refuses a lane where that happened. `ci-journeys.mjs` puts the cook journeys last. The drag uses Playwright `dragTo`, which drives the HTML5 drag events in Electron's Chromium.
- Opening the reference reel switches to the browser tab; `plan-01` reopens Plan from "+" to come back to the same board tab.

- The "+" path needs a tab bar and the sidebar rows need an active worktree, so these journeys need a project open, as for `shell-01`. A first launch has none: `fresh-lane.sh` starts the app with no project (`APP_NO_REPO=1`) and runs `fresh-01`, which clicks each board row (`today`, `funnel`, `own`, `rivals`, `plan`, `agents`) and expects a board tab, then Sources. With no workspace the first row adds and activates the "Lead Studio" folder workspace next to the lane's database (`openBoardInActiveWorkspace`, `src/renderer/src/lib/open-board-tab.ts`), and every row then opens its board there.
- The app menu is native; CDP cannot click it. The journey covers the "+" menu path only.
- A board tab is not restored after a restart.
- If `rivals-01` dies between the two renames, the lane DB keeps `video_analyses_off`; `app-down.sh` and a fresh lane reset it.
- On `boards-lane.sh` the app's background sync reaches the fake sidecar and gets 503, so the rival row shows that sync error. Without the fake sidecar, Add rival shows the sidecar-down error and writes nothing.
- Rivals' follower count, median views and outliers move only from a complete channel pull: a sync cut mid-walk leaves them as they were and marks the job `partial`. No journey drives that, because a lane makes no Instagram calls; the proof is the B1-07 test in `src/server/services/sync-engine.test.ts`. A journey run checks only that the seeded numbers still show.
- The light screenshots drop the `dark` class on `<html>` for the snap and put it back, with the app's `theme-transition-disabled` class on during the swap so the snap does not catch text mid-fade; the theme setting does not change. Each journey also waits for the "+" menu to close before its first snap.
- Token and fake-secret names carry a timestamp, so both journeys rerun on the same lane.
- `today-01` sizes the page with `setViewportSize`: Electron's CDP has no `Browser.setWindowBounds`. Each rerun proposes one more week plan version, and the gate check reads the DB, so it still holds.
- A failed newest pull on Today and Funnel shows only on the baseline lane, which seeds a failed Graph pull for today ([baseline.md](baseline.md)); `src/server/queries/funnel-board.test.ts` proves the mapping.
