# llm: test cases

Result markers: 🟢 pass, 🔴 bug, 🟡 blocked (missing dependency named in the cell). Rows still reading "not run" were not driven in QA round 1.

How to run these: the llm layer has no screen of its own, so most cases are verified through the surfaces that call it. Start the dev server and open `http://localhost:3001` (never `127.0.0.1`), on a database with at least one tracked channel that has finished a sync and at least one analyzable video (a stored transcript or a reachable transcript provider). Toggle the two llm inputs independently: set or unset `ANTHROPIC_API_KEY` (unset for the no-key state), and set or unset `LLM_BASE_URL` to a local 9router (unset for the native path, set for the compat path). A key set through the Settings API Keys card lands in the database and wins over the environment. The layer's code-level behavior (retry, loose-JSON parse, error mapping, probe timing) is covered by `src/server/llm/client.test.ts`, `error-message.test.ts`, and `generation-probe.test.ts`, run with `vitest`, temporary SQLite database.

## 3. browse-e2e

The llm layer has no screen of its own, so its journeys drive the two surfaces that call it directly: the Settings API keys card's Anthropic Test button (feature 3's `ping`) and the 9router supervisor section (feature 3's generation probe), plus the caller surfaces that reach feature 2 (the video detail Analyze button and a remix generation stage). Every built feature in the `03` summary has a happy-path journey below: feature 2 (E2E-02) and feature 3 (E2E-01). The `Structured layout reads` frame pass is `○` roadmap, so it needs none.

Corner-case types marked not applicable for this layer:

- `empty`: the layer holds no data of its own and renders no zero-data list, so there is no empty state it owns; a caller's empty feed is that caller's case.
- `boundary`: the layer exposes no user-facing count, page size, or cap; `max_tokens` (2048 native, 8192 compat) is an internal default with no UI edge to sit at.
- `invalid`: the layer validates model output (retry then `LlmParseError`), not user input; the only text field on any surface here is the masked key input, owned by the secrets and settings component, not this layer.
- `stale`: the layer is stateless and writes nothing, so there is no optimistic UI or reload-reconciliation window it owns; a key set in Settings applies on the next call via `resetLlmClient()` with no intermediate state a user reads.
