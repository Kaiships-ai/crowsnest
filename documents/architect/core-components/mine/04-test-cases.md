# mine: test cases

How to run this file: bring up `/mine` on `http://localhost:3001` (never `127.0.0.1`) with one tracked channel marked as your own, and a Graph token that has measured the account at least once, so the dashboard, the six stat tiles, and the reach bars carry real numbers. If no channel is marked own yet, the page is a picker; click "This is me" on a tracked channel to reach the dashboard. Seed a handful of planned posts spread across a draft with no date, a scheduled future date, and a scheduled past date, plus at least one plan carrying a script and one plan marked published, so the calendar cells exercise every state. Keep a way to invalidate the Graph token (clear or corrupt it) so the connect panel and the stale metrics rows can be checked. Needs column values: `mouse` and `keyboard` are the input; `graph-invalid` means the Graph token is cleared or rejected; `graph-measured` means the account was measured at least once before; `second-tab` is a second tab on the same session, not a second browser; `soft-remove` means a row marked `deletedAt` underneath a read; `db-read` means the claim is about a stored value a database read or the test suite can stand in for.
