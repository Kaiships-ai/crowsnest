| OBS-3 | Platform chips promise TikTok and YT Shorts, but only Instagram is ingested. In review: no live control actually offers TikTok or YouTube Shorts today — the add-channel dialog's platform picker and the feed toolbar's platform filter were both already removed (2026-07-28 and 2026-07-31, before this row was filed), and `PLATFORM_META` in `platform-chip.tsx` maps only `"instagram"`, so any other value falls back to its own raw string rather than a branded label. What was missing was a regression test locking that in, so a future edit could silently reintroduce a branded TikTok or YouTube Shorts chip without anything failing. Added `src/components/feed/platform-chip.test.tsx` (asserts `platformLabel`/`PlatformChip` never brand `"tiktok"`/`"youtube_shorts"`) and a case in `src/components/channels/add-channel-dialog.test.tsx` (asserts the dialog renders no platform picker at all). The `platform` column and its type union stay multi-valued in the schema for a later platform, per the existing design call | medium | bug | observed-bugs | in-review |
