# studio: test cases

How to run this file: start from a planned post that has a saved script attached and a source
video, opened in the studio at `/mine/{postId}/studio` (reach it from the remix finish stage or
from the plan dialog's "Create in Studio" button). Most brief rows are a plain read and need only
that plan on screen. The run-state and publish rows need a real cook: click Cook and let the
terminal session drive an actual run to a render, since the render is what gates Publish and what
Save to calendar captures live. To reach a render, cook a post whose session can complete; a run
that fails or is stopped leaves no publishable render. For the reload rows, keep one cook running
and reload the page while it is still working. The suspected-bug rows only ask you to record what
happens.
