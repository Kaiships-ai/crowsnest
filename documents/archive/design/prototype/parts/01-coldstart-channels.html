no heartbeat for 90 seconds

The run has probably died holding the lock, but it may yet recover.

The hedge is the point. The stale-lock reaper waits 900 seconds before stealing the lock, so inside that window a run that looks stalled can still be alive. When the reaper fires it writes failed with SYNC_ABANDONED. Stalled takes red rather than amber, because amber would read as "still going".

state machine: idle, running, stalled, cancelling, cancelled, success, partial, failed. Stalled outranks cancelling, because a dead process will never honour a cancel. And failed plus stop reason cancelled reports as a failure, not a cancellation.
