plan. All commands were run on this Mac against the local dev database with real synced
data (1114 posts across 13 channels).

artifacts" acceptance test, passing on real data with no internal API key.

## Known limitations and the one real blocker

- Multi-account sync runs accounts sequentially with isolated per-account state today. Live
  bounded-parallel-across-accounts IG traffic (one live sidecar per account) is built for
  in structure (account ports, session paths, `accountChildEnv`) but not run or verified,
  because it needs live per-account Instagram credentials, which are the operator's to
  provide. This is the single named blocker (see multi-account.md).
- Fresh live IG sync during this session was not possible: the sidecar was not running and
  the burner credentials are the operator's. The dogfood therefore ran on the real data
  already synced into the local database, and the sync-control tools were exercised by the
  MCP roundtrip and unit tests, not a live pull.
- Minor UI polish deferred: the Logs screen relies on the route-level error boundary rather
  than an inline error panel.
