# Standing rules (Kai)

- **Update the docs when you finish a change.** Any new or changed component, nav,
  behavior, route, or config: update its owning doc under `documents/` (the part's
  `documents/architecture/<part>.md`, and `scripts/e2e/cases/<component>.md` for features and test
  cases) in the same PR. A change is not done until its doc is true. A new component gets an
  architecture page and a cases file.
