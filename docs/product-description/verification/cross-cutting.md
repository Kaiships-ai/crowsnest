# Verification: cross-cutting

How to run this file: bring up the surface per the [protocol](README.md#how-to-run-a-pass) with a database that has at least one tracked channel with analyzed videos and one remix session in progress, then drive each row by putting a single backing service into the state it needs. Stop the proxy (or unset `LLM_BASE_URL`) for the proxy down rows, and note this is not the same as no key: unset `ANTHROPIC_API_KEY` for the no key rows, which read differently. Clear or invalidate the Graph token for the connect panel rows, and keep a channel that was measured before so you can tell the never measured state from the measured then invalidated one. Stop the sidecar for the stale feed rows. Restore each service between sections so a leftover down state does not bleed into a row that needs it up. Most rows here also turn on a reload or a navigation, so keep a second tab on the same record ready (a second tab shares the session, it is not a second browser), and reload with the service in the stated state, not after restoring it. The Needs column names the one condition a row turns on: `proxy down`, `no key`, `graph invalid`, `sidecar off`, `whisper only` (whisper.cpp installed, no Groq key, no Anthropic key), `reload`, `second tab`, `cook fail`, or `mouse` for an ordinary read.
