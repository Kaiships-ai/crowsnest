# Verification: remix

How to run this file: bring up the surface per the [protocol](README.md) and open `http://localhost:3001` on a database with at least one tracked channel whose videos are analyzed. Pick one source video that is analyzed and has a transcript, and open its remix at `/feed/{videoId}/remix`; that one session carries every stage below. Several items toggle the LLM proxy: run the generation and blocked-panel rows once with the proxy up and a key set, once with `ANTHROPIC_API_KEY` unset (the no-key state), and once with a key set but the proxy stopped (the proxy-down state, which the studio infers from a recent failed run-log row, so you may need one failed attempt to arm it). The Graph token and the sidecar do not gate any remix stage; leave them as they are. For a clean pass, start from a fresh session (a video never remixed) so the prompt prefill and the furthest-stage rules read from a known start.
