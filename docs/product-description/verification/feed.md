# Verification: feed

How to run this file: start the dev server and open `http://localhost:3001` (never `127.0.0.1`), on a database with at least one tracked channel that has finished a sync, so the feed has scored videos to show. Seed a mix: at least one analyzed video and one unanalyzed one, one outlier scoring at or above 1.0 and one below, one video with a transcript and one without, one carousel post, and one video you can soft remove (set `deletedAt`) to check the removed paths. Analyzed videos are the precondition for the detail-page actions (analyze, save to vault, generate idea, keep), so an analyzed video is needed to reach most of the DETAIL, ANALYZE, VAULT, KEEP, and IDEA rows. To reach a clean feed state, open a bare `/feed` (the High Conviction view applies) or click Show all for the whole library; note the results count you start from so a Load more or a filter change reads as a real change. The feed, the filter bar, the quick preview, and rendering the detail page need no external service. The rows that do need a service toggle say so in the Needs column: the add-post import needs the post-fetch provider reachable; analyze needs a transcript provider (whisper.cpp local or a Groq key) and the Claude API key; generate idea needs the LLM proxy up and a key. Stop the LLM proxy (or unset `LLM_BASE_URL`) for the proxy-down state, and unset `ANTHROPIC_API_KEY` for the no-key state; the two read differently. "A soft removed video" means a video row with `deletedAt` set. "A second tab" shares the session; it is not a second browser.
