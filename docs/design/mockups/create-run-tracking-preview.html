Create-run tracking

Today a cook runs inside the embedded terminal and Crowsnest cannot see it — the only signal back is the finished file. This gives a cook a tracked run: a status strip in the studio, and durable records on /runs and /runs/[runId]. One run per Cook press; Stop ends a run early, Retry cook always starts a new one.

Stop appears only while a cook is running and ends the session (the run moves to Canceled). Retry cook appears once a run has a result — success, failed, or canceled — and always starts a new run, never resumes the old one. Amber stays reserved for the score badge and the running-state pill. A render crash (for example ffmpeg exited 1) fails the same way as the timeout shown here, just with a different error line.
